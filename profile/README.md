## Highlights

|  | 方向 | 仓库 | 说明 |
|--:|:---|:---|:---|
| ◆ | **Prism** | [`Prism.SourceGenerators`](https://github.com/MvvmAIO/Prism.SourceGenerators) | Prism 路线下的分析器与源生成器 |
| ◆ | **XAML** | [`MvvmAIO.Markup`](https://github.com/MvvmAIO/MvvmAIO.Markup) | 面向 WPF 与 Avalonia 的常用 CLR 类型 XAML 标记扩展 |
| ◆ | **文档** | [`Prism.SourceGenerators.Docs`](https://github.com/MvvmAIO/Prism.SourceGenerators.Docs) | VitePress 多语言文档站 |
| ◆ | **示例** | [`Prism.SourceGenerators.Samples`](https://github.com/MvvmAIO/Prism.SourceGenerators.Samples) | Avalonia、WPF、MAUI、Uno 示例工程 |

> Looking for **R3** reactive source generators? The archived `MvvmAIO.R3.SourceGenerators` packages have moved to **[Skymly/Observables](https://github.com/Skymly/Observables)** (`Observables.Events.R3`, etc.).
